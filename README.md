# kaktus.dev 🌵

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/I2I31CXQVM)

Un proyecto de marca personal minimalista y un catálogo interactivo masivo de patrones de diseño web modernos de alto rendimiento. Utiliza transiciones de CSS fluido y APIs nativas del navegador sin dependencias de JavaScript o frameworks pesados.

---

## 🎨 Patrones de Diseño e Interacción Incluidos (38 Ejemplos)

El showcase contiene los siguientes **38 ejemplos interactivos** que demuestran capacidades avanzadas del navegador moderno:

1. **01 / GLOW · Foco de Cursor en CSS**: Iluminación del borde de la tarjeta siguiendo las coordenadas del ratón mediante variables CSS (`--x`, `--y`).
2. **02 / HEIGHT · Acordeón Nativo**: Menús desplegables fluidos y animados usando la etiqueta HTML `<details>` y transiciones de CSS Grid sin una sola línea de JS.
3. **03 / PORTAL · Popover API Nivel Top**: Modales nativos ligeros y accesibles con cierre automático gestionado por el navegador (`popover` y `::backdrop`).
4. **04 / ENCRYPT · Text Decode Effect**: Animación de decodificación clásica donde los caracteres se barajan aleatoriamente hasta encajar en el mensaje final.
5. **05 / PERSPECTIVE · Matriz de Rotación 3D**: La tarjeta se inclina de forma reactiva al cursor siguiendo cálculos de perspectiva tridimensional.
6. **06 / FLUID · Neon Switch Bouncy**: Interruptor con estética de neón que utiliza transiciones de amortiguamiento y resorte elástico en CSS puro.
7. **07 / FROST · Glassmorphism & Depth**: Panel de vidrio esmerilado con desenfoque de fondo nativo (`backdrop-filter`) enmascarando una esfera de color flotante.
8. **08 / MOTION · Amortiguamiento Físico**: Simulación de elasticidad al pulsar un botón con fotogramas clave que reproducen un rebote físico natural.
9. **09 / MASK · Máscaras y Recortes CSS**: Recortes invertidos en los bordes simulando entradas de cine clásicas usando máscaras radiales nativas de CSS.
10. **10 / MAGNET · Atracción Magnética**: El botón se desplaza de forma interactiva hacia el cursor en su zona de atracción simulando magnetismo.
11. **11 / LIQUID · Filtros SVG Gooey**: Efecto de viscosidad y fusión líquida entre círculos usando un filtro SVG personalizado (`feGaussianBlur` y `feColorMatrix`).
12. **12 / SPECTRUM · Espacio de Color OkLch**: Selección y transiciones cromáticas en el espacio OkLch para una consistencia de brillo perceptible perfecta.
13. **13 / TRACK · Anillo de Progreso Scroll**: SVG circular interactivo que se dibuja automáticamente en base al porcentaje de lectura del scroll de la página.
14. **14 / GRAIN · Grano de Película Analógico**: Capa animada de ruido dinámico simulando grano fotográfico, con un regulador de intensidad interactivo.
15. **15 / RIPPLE · Ola Escalonada**: Letras individuales que se elevan y oscilan secuencialmente mediante retardo de transición indexado (`transition-delay`).
16. **16 / PAN · Lienzo Infinito**: Cuadrícula técnica interactiva que el usuario puede arrastrar y reposicionar libremente con el ratón.
17. **17 / DISTORT · Lente de Distorsión**: Malla cuadriculada que se deforma y amplía bajo una lente de aumento física que sigue al ratón.
18. **18 / FLUOR · Neon Reactivo**: Caracteres que destellan con iluminación fluorescente instantánea al contacto físico y se atenúan progresivamente.
