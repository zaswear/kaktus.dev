# Security Policy

## Supported Versions

We actively monitor and support security patches for the latest version on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover any security vulnerability (such as script injection vectors, clipboard hijacking risk, or clickjacking vulnerabilities in the code viewer tool), please **do not open a public issue**. 

Instead, report it directly to the maintainer:
* **Contact Email**: [zaswear@gmail.com](mailto:zaswear@gmail.com)

We will respond within 48 hours to acknowledge the receipt of the report and coordinate a fix release. Thank you for helping keep the developer community safe!
